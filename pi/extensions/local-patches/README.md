# Local upstream patches

`@mjakl%2Fpi-subagent@3.0.1.patch` adds explicit public Pi RPC entry resolution for Bun child launches. See [subagent child verification](../../../docs/subagent-child-verification.md) for the upstream proposal, real-child tests and remaining verification constraints.

`pi-mcp-adapter@2.32.1.patch` adds two host APIs to the package entry point: `readMcpResourceV1(pi, {version: 1, server, uri}, {signal})` and `callMcpAppToolV1(pi, {version: 1, server, tool, args}, {signal})`. Requests and raw MCP result envelopes are JSON-safe. The Pi instance and cancellation signal are out-of-band authority/lifecycle arguments. Errors reject the promise.

The npm latest release is 2.32.1 at the time of verification. Its resource proxy renders content instead of supplying raw MIME, metadata and unlisted resources. Its model catalog correctly excludes App-only tools. Pixie's retained Apps interface needs raw resource access and a separate App-origin call path. The patch reuses upstream's manager, connections, auth, visibility helpers and configured tool approval flow. It does not export the manager, add transports, register tools, change model visibility or grant authority based on a supplied session ID. Calls are bound to the installing ExtensionAPI and capture the lifecycle generation before awaiting work. Shutdown, session replacement and cancellation reject outstanding calls.

The proposed upstream API is the same narrowly scoped export. A future upstream release with an equivalent supported API should replace this patch after the resource, cancellation and Apps contract tests pass. No upstream submission is made automatically.

The support boundary is 2.32.1 plus 113 added lines in `index.ts`, with no deletions. The API and factory must resolve from the same package instance. The host must authenticate the caller and authorize AppView ownership and same-server access before invoking the App API. App-only and default-visible tools are callable. Explicit model-only tools are rejected. Upstream configured approval uses origin `iframe` and remains enforced. Pixie selects `pi.apps.tools.call` only after its controller checks, never from a browser-provided origin flag. Model/admin `pi.tools.call` stays on the model proxy. The default switch and complete Apps capability are covered by the retained contract tests.

Bun applies this patch through the root `patchedDependencies` declaration and lockfile. Reproduce with `bun install --frozen-lockfile` using the repository's pinned Bun. To revise it, use `bun patch pi-mcp-adapter@2.32.1`, edit the prepared package, then `bun patch --commit node_modules/pi-mcp-adapter --patches-dir pi/extensions/local-patches`. Here `--commit` is Bun's patch-generation command, not a Git commit.
